# Fast Explorer

Windows のファイルサーバー（UNC / SMB）を、エクスプローラーより速く一覧するための軽量ファイルエクスプローラーです。一覧は PowerShell の `Get-ChildItem` に近づけ、名前と基本属性だけを読みます。

## Windows エクスプローラーが遅い理由

エクスプローラーはフォルダを開くとき、ディレクトリのエントリを読むだけでは終わりません。表示の前後で次の処理が走ります。

- **シェル拡張**。右クリックメニュー、追加カラム、インフォチップなどの COM 拡張が、フォルダごとに読み込まれます。ネットワーク共有では、この読み込み自体が往復になります。
- **サムネイルとプレビュー**。画像、PDF、Office 文書などは中身を開いて縮小画像やプレビューを作ります。共有上のファイルでは、一覧に不要な読み取りがファイル数だけ増えます。
- **プロパティハンドラ**。サイズや更新日時以外の詳細（タグ、撮影日、ページ数など）を、ファイル種別ごとのハンドラが取りにいきます。
- **アイコンの解決とアイコンキャッシュ**。ファイルごとに関連付けアイコンを引きます。`FileSystemView.getSystemIcon` を 1 件ずつ呼ぶのと同じ種類のコストです。

遅延の大きい共有では、この「1 ファイルあたりの追加ラウンドトリップ」がそのまま待ち時間になります。`Get-ChildItem` は `FindFirstFile` / `FindNextFile` で名前と基本属性を取るだけなので、体感が違います。Fast Explorer はそのやり方に寄せています。

## 設計

- 一覧は Java NIO の `DirectoryStream`（`Files.newDirectoryStream`）だけです。`File.listFiles` も、シェル拡張も使いません。
- アイコンはフォルダ用とファイル用（とリンク用）の汎用画像だけです。ファイルごとのアイコン解決、サムネイル、プロパティハンドラはありません。
- 属性は `BasicFileAttributes` の 1 回分だけです。Windows の `DirectoryStream` は `FindNextFile` の `WIN32_FIND_DATA` を内部の `BasicFileAttributesHolder` としてパスに載せます。`Files.readAttributes` はそのキャッシュを見ないので、JVM に `--add-opens java.base/sun.nio.fs=ALL-UNNAMED` を付けてホルダを直接読みます。載っていないエントリ（`FindFirstFile` の先頭 1 件、Linux、フラグなし起動）だけ `Files.readAttributes` を 1 回呼びます。サイズを保存するのは通常ファイルだけです。ディレクトリは「—」と出します。
- 結果はユーザーホームの埋め込み H2（`~/.fastexplorer`）に保存します。ファイル名は小文字化した列 `name_lower` にインデックスがあります。
  - **期限内**: キャッシュをすぐ出して終わります。
  - **期限切れ**: キャッシュをすぐ出し、裏で取り直してから表を差し替えます（stale-while-revalidate）。取り直しに失敗したときは、キャッシュを残してエラーを出します。
- 検索は、まず H2 の `LIKE`（インデックス付きの `name_lower`）で現在のフォルダ以下を引き、すぐに表示します。拡張子を指定したときは、小文字の `ext` 列（インデックス付き）で絞ってから返します。そのあと、キャッシュが無いフォルダと期限切れのフォルダだけをバックグラウンドで歩き、同じ条件で結果をキャッシュへ書きながら表へ流します。中止できます。
- ファイルシステムと DB はバックグラウンドスレッドです。別のフォルダへ移ると、前の一覧は世代番号で捨てます。ステータスバーに件数、所要時間、キャッシュかファイルシステムかを出します。
- 左側のお気に入りはグループ（入れ子可）とフォルダのツリーです。クリックでそのパスを開きます。UNC でも、開く処理はバックグラウンドなので画面は止まりません。内容は `favorites.json` に保存します。
- アクセス拒否、見つからないパス、応答しないサーバー、タイムアウトはダイアログで止めず、画面上のメッセージにします。ネイティブ呼び出しが割り込めない場合でも、待ち受け側はタイムアウトで戻ります（残った処理はデーモンスレッドです）。

## 必要環境

- JDK 21
- Maven 3.8 以降
- Windows 10 / 11（UNC を開く場合）

Linux でもローカルディスクに対するビルド、テスト、起動はできます。UNC の実体は Windows 向けです。

## ビルド

```bat
mvn test
mvn -DskipTests package
```

成果物は依存関係を同梱した `target\fast-explorer.jar` です。

## 起動（Windows）

コマンドプロンプト:

```bat
java --add-opens java.base/sun.nio.fs=ALL-UNNAMED --add-exports java.base/sun.nio.fs=ALL-UNNAMED -jar target\fast-explorer.jar
```

共有を直接開く:

```bat
java --add-opens java.base/sun.nio.fs=ALL-UNNAMED --add-exports java.base/sun.nio.fs=ALL-UNNAMED -jar target\fast-explorer.jar \\fileserver\share\projects
```

`run.bat` は同じフラグで JAR を起動します。

```bat
run.bat \\fileserver\share\projects
```

`--add-opens` は、列挙時に付いている属性キャッシュを読むためのフラグです。JAR をダブルクリックした場合、Windows ではフラグ付きで 1 回だけ再起動します。フラグが無くても動きますが、そのときはエントリごとに `readAttributes` します。

Linux / macOS:

```bash
./run.sh
./run.sh /path/to/folder
```

### VS Code

フォルダを開き、Extension Pack for Java で Maven プロジェクトとして読み込みます。`.vscode/launch.json` の **Fast Explorer** を実行すると、上の JVM フラグ付きで起動します。テスト実行用のフラグは `.vscode/settings.json` にあります。

## 使い方

- アドレス欄に `\\server\share\folder` または `D:\data` を入れて Enter（相対パスは現在のフォルダ基準）
- フォルダをダブルクリックまたは Enter で開く。ファイルは Windows の関連付け（`Desktop.open`）で開く
- 戻る / 進む / 上へ（Alt+← / Alt+→ / Alt+↑、一覧にフォーカスがあるときは Backspace で上へ）
- F5 または「更新」で、キャッシュを表示したうえで取り直す
- 検索条件は 4 つの欄です。含める(ファイル)、除外(ファイル)、含める(フォルダ)、除外(フォルダ)。カンマ、空白、セミコロンで複数指定でき、大文字小文字は区別しません。`*` と `?` はワイルドカード、それ以外は部分一致です。含めるが空ならすべてが対象です。ファイルの条件はファイル名だけを見ます。フォルダの条件は、検索を始めたフォルダからの相対パスにあるフォルダ名を見ます（`src/main` のようにスラッシュを含む指定はパス全体）。除外(フォルダ) に入れた `node_modules` や `.git`、`target` は結果から外し、検索の歩きとインデックス作成でも中に入りません
- 検索結果の「場所」は、初期状態では検索を始めたフォルダからの相対パスです（`sub\dir\file.txt`）。「相対 / 絶対」でフルパスに切り替えられ、設定の `path.display` に残ります。行にマウスを載せるとフルパスが出ます。場所列はその表示文字列で並べ替えできます
- 右クリックの「パスをコピー」から、フルパス、相対パス、ファイル名、フォルダ名（ファイルなら親フォルダ名）をコピーできます。複数選択したときは 1 行に 1 件で、Windows では CRLF です
- 拡張子欄は `java, xml, .txt` のようにカンマや空白で複数指定できる。空欄はすべて。最後のドットより後ろだけを見る（`archive.tar.gz` は `gz`、`.gitignore` は拡張子なし）。大文字小文字は区別しない。横の一覧から文書・表計算・画像・ソースを入れることもでき、使った指定は「最近」に残る
- 検索は「検索」ボタン、または条件欄・拡張子欄で Enter（履歴のドロップダウンが閉じているとき）だけで始まります。拡張子のプリセット、履歴の選択、「フォルダを含める」、「相対 / 絶対」では検索を始めません
- 「フォルダを含める」を外すと、今開いている一覧からフォルダを隠します（検索は始めません）。検索結果に対しては、次に検索を実行したときに効きます。拡張子の入力も、一覧表示中はすぐ絞り込み、検索中は Enter か「検索」まで待ちます
- 「ダーク」「ライト」で外観を切り替え（設定ファイルに保存）
- Ctrl+L でアドレス欄、Ctrl+F で検索欄
- 戻る / 進む / 上へは矢印ボタンです。使えないときは薄くなります

### 右クリック

一覧でも検索結果でも、行を右クリックします。

- フォルダ: 「エクスプローラーで開く」「インデックス作成」。お気に入りのフォルダでも同じことができます
- ファイル: 「ファイルの場所をエクスプローラーで開く」。`explorer.exe /select,"パス"` で、UNC でもそのファイルを選択した状態で開きます
- ファイル: 「オリジナルを開く」で、サーバー上のファイルを関連付けアプリで直接開きます。「外部エディタで開く」は設定したエディタでサーバー上のファイルを開きます（設定 → 外部エディタを設定）
- ファイル: 「ローカルのキャッシュを開く」と「ローカルのキャッシュを読取り専用で開く」。共有上のファイルを `filecache` にコピーしてから関連付けで開きます。サイズと更新日時が前回と同じならコピーせず、ローカルのコピーをすぐ開きます。コピーは一時ファイルに書いてから置き換え、サーバーへの書き戻しはしません。読取り専用は、開く前にローカル側だけ読み取り専用にします
- 「パスをコピー」から、フルパス、相対パス、ファイル名、フォルダ名をコピーできます
- エクスプローラーの項目は Windows 以外では使えません（メニューは残し、無効になります）

コピー中はステータスバーに進み具合が出ます。「中止」で中断できます。メニューの「ローカルキャッシュを開く」「ローカルキャッシュを消去」で保存先を開いたり、古いコピーから捨てたりできます。上限を超えると、使っていないコピーから消します。

### インデックス

フォルダの右クリック、お気に入り、または「表示 → このフォルダをインデックス」で、そのフォルダ以下の一覧を H2 に先に書きます。あとからの検索はインデックスに当たりやすくなります。走査は専用の 1 スレッドで、画面や通常の移動は止めません。到達できないフォルダは飛ばして続けます。同じパスや親子関係にある実行中のジョブがあるときは、新しいジョブは始めません。

右の「インデックス」タブに、パス、状態（完了 / 実行中 / 中断 / エラー）、最終実行時刻、フォルダ数、ファイル数、所要時間が出ます。実行中は件数が更新されます。ダブルクリックでそのフォルダを開きます。再インデックス、中止、削除（確認あり。その範囲の検索キャッシュも消します）ができます。

### 入力履歴と前回のフォルダ

アドレス、4 つの検索条件、拡張子は履歴付きの入力欄です。新しいものが上で、同じ文字列は大文字小文字を無視して 1 件にまとまります。入力すると履歴から補完します。ドロップダウンを開いて Delete、または右クリックの「この履歴を削除」で 1 件消せます。「ファイル → 入力履歴を消去」で全部消します。件数の上限は `history.max.entries`（既定 50）です。

起動時は、前回開けたフォルダを裏で開きます。コマンドにパスを渡したときはそちらが優先です。前回のフォルダが応答しないときは、キャッシュがあればそれを出し、無ければホームを表示します。起動自体は待ちません。

### お気に入り

ウィンドウ左側のツリーです。境目はドラッグで変えられ、位置は設定ファイルに残ります。

- 「現在を追加」で、今開いているフォルダを追加する。グループを選んでいるとその中に入る
- 一覧のフォルダを右クリックして「お気に入りに追加」、またはツリーへドラッグする。右クリックでの追加も、選択中のグループがあればその中に入る
- 「グループ」で分類用のフォルダを作る。グループの中にグループも置ける
- 右クリックで名前の変更、削除、上へ / 下へ、別のグループへの「移動」。ツリー内のドラッグでも並べ替えとグループ間の移動ができる
- 上の入力欄は表示名とパスを部分一致で絞る（大文字小文字は区別しない）。一致した項目の親グループは残る。グループ名が一致したときは、その中身をすべて出す
- お気に入りをクリックするとそのフォルダを開く。サーバーが遅くても、一覧の読み込みは裏で行う
- メニューの「お気に入りを書き出す…」「お気に入りを読み込む…」で同じ JSON をやり取りする。読み込みは現在のツリーを置き換える

保存先は設定フォルダの `favorites.json` です。

## 設定

初回起動で次のファイルを作ります。

- Windows: `%USERPROFILE%\.fastexplorer\config.properties`
- Linux: `~/.fastexplorer/config.properties`

```properties
# キャッシュの有効期限（秒）。期限内はキャッシュだけを表示します。
# 0 にすると、キャッシュをすぐ表示したあと毎回ファイルシステムで更新します。
cache.ttl.seconds=120

# フォルダ 1 つあたりのタイムアウト（秒）
listing.timeout.seconds=30

# 検索時に歩くフォルダ数の上限
search.max.directories=5000

# 検索結果の上限
search.max.results=5000

# light または dark
theme=light

# 固定の起動パス（任意）。last.path が空のときだけ使います。コマンド引数があるときは引数が優先されます。
initial.path=

# お気に入りパネルと一覧の境目（ピクセル）
favorites.divider=260

# 前回表示していたフォルダ。次回起動時に開きます。コマンド引数があるときはそちらが優先されます。
last.path=

# アドレス・検索・拡張子の履歴の最大件数
history.max.entries=50

# ローカルファイルキャッシュ。空なら設定フォルダの filecache。上限は MB
filecache.dir=
filecache.max.mb=2048

# インデックス作成で潜る深さ。0 は制限なし
index.max.depth=0

# 検索結果の場所。relative（検索を始めたフォルダから）または absolute
path.display=relative

# 外部エディタの実行ファイル（右クリックの「外部エディタで開く」）
# 例: C:\\Program Files\\Microsoft VS Code\\Code.exe
external.editor=
```

キャッシュ DB は同じフォルダの `cache.mv.db`、お気に入りは `favorites.json`、入力履歴は `history`、インデックスの記録は `index-meta` です。メニューの「設定フォルダを開く」からも開けます。数値として読めない項目は既定値に戻します。

## テスト

GUI は不要です。一時ディレクトリと H2 で、一覧、お気に入り、拡張子、ファイルキャッシュ、インデックス、入力履歴を検証します。

```bat
mvn test
```

JAR の疎通確認（画面なし）:

```bat
java -jar target\fast-explorer.jar --self-check
```

`self-check: OK` と出て終了コード 0 なら、一覧・キャッシュ・名前検索・お気に入りの保存が通っています。

## 制限

- 応答しないサーバーへの最初のシステムコールは、Java から中断できないことがあります。タイムアウト後に画面の待ちは終わりますが、その処理用デーモンスレッドが残ることがあります。アプリ終了の妨げにはしません。
- 検索の `LIKE '%キーワード%'` は部分一致です。インデックスが最も効くのは前方一致ですが、キャッシュ済みの名前はファイルシステムより先に返します。
- 検索は現在のフォルダ以下で、歩くフォルダ数に上限があります。ドライブ直下から広い検索を掛けると、上限まで共有を歩きます。中止できます。
- ディレクトリへのシンボリックリンクは、リンク先の中までは自動では歩きません。ジャンクションなどで列挙結果がディレクトリになるものはフォルダとして開きます。
- サムネイル、プレビュー、エクスプローラーの拡張列は入れていません。
